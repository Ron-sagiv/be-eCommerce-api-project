E-COMMERCE-API

Setup
Create a .env file and add the properties with values MONGO_URI

API end points
API endpoint to use: http://{host}:{port}/api/users http://{host}:{port}/api/products http://{host}:{port}/api/orders http://{host}:{port}/api/categories http://{host}:{port}/api/shoppingCarts
